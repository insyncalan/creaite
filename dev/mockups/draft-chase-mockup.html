Draft chase, from the peek

A new Draft chase icon in the work-item peek's top bar, to the left of Copy link. It writes a ready-to-paste email for Outlook, using the same builder and look as the Draft email on a person's page, and it reads whose action it is: when it is someone else's it chases them; when it is yours it asks for help, making clear the action is yours. The icon

  • An envelope with an arrow, in the peek's top bar to the left of Copy link; key C while the peek is open. Shown for an open action, risk, issue or decision; hidden for closed items.
  • It opens the chase inside the peek (Back returns to the item), so the item stays in view beside Work.

How it reads the item

  • Someone else's: a chase to the owner (their email from the people register), in BL-224's tone: first reminder, second, then firmer, from how often it was chased.
  • Yours: a request for help. The opening is "I've been asked to follow up with you on …, to get … done", it says the action is yours, and "What I need from you" is its own line. You pick who it goes to; creaite suggests people from the item (named in its updates, who raised it, the meeting it came from, the project's stakeholders).
  • A decision: to the decision maker, asking for the decision by its needed-by date.

Rules it keeps

  • No model call: the same deterministic builder as the Draft email. An optional Polish (AI drafts) rewords it, with the switch in Settings › AI drafts.
  • Never sends and never makes an Outlook draft: Copy for Outlook copies formatted HTML with a plain-text fallback.
  • I sent it records the chase (ID, date, mode) in chases.json, so the next one steps up and the person's page shows it. Nothing reaches the tracker.
  • The subject keeps the project code in brackets, so Outlook rules can file it. The body uses the project's name. A followed person is never labelled (BL-288).
