What changed from the last mockup

  • Save agenda opens the document at once. No banner, no "Open it", no "Show in Files": the agenda is a creaite document you are already in (a small "v1 · saved just now" in the bar).
  • It stays editable, like the minutes: an A4 page (zoom 40 to 80%, Show as exported), edited in place with the shared rich editor (the / menu, the sparkle and selected-text bar, links); ✦ beside a section redrafts it (Keep mine or Use this); saved as you go with a version shown in the bar; Versions and Copy as text under …; Export ▾ to HTML, Word or PDF (never sent).
  • Items are rows in the page: add with "+ Add an item" (type # or words, or make a new action), remove with ✕; pointing at an ID shows the card after about 0.6 s; clicking a row opens the standard work-item peek beside the page, where you edit and update (changes are proposals, the row follows at once).

Delete and Start over, discreet

  • Both live under the … menu, last, Delete in red, exactly where Notes puts Delete.
  • Delete agenda…: confirm box, then the one approval card for the move into the project's archive (only Approve moves it); restore from Files › Archived; the prep page and its notes are kept.
  • Start over…: confirm box; clears the agenda and drafts it again from today's items; the current one is kept as a version, so it is undoable.
  • Edit again is no longer an action: you edit inline; Versions covers going back.
