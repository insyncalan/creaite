Links in editors

#120. One Link control, four ways in: a toolbar button, the / menu, the shortcut ⌘⇧K (⌘K stays the search), and pasting. Use the steps to walk through it, or try it: select words and press the toolbar link button or ⌘⇧K; click a link; paste an address (the buttons simulate the paste).

Purpose

Agree the revised data-sharing agreement with the client's legal team before UAT starts. The latest draft is in the project folder.

See also the sponsor's briefing page and the delivery checklist for details.

The behaviour

  • Four ways in: the link button in the formatting bar; "Link" in the / menu (Link group, with a description); the shortcut ⌘⇧K (Ctrl+Shift+K off a Mac; ⌘K is the search palette); pasting an address.
  • Add or edit: a small popover under the words: Text (the selected words, editable) and Address (cursor here). Enter applies, Esc cancels. A bare domain ("example.com") gets https:// in front. With no words selected, Text is the address.
  • An existing link: click it, or put the cursor in it: a one-line popover shows the address with Open ↗ (a new tab, no referrer), Edit and Remove (Remove keeps the words, drops the link). A plain click on a link only shows the popover; Open is explicit, so you never leave the note by accident.
  • Paste an address over selected words: the words become a link (toast "Linked", Undo). Paste a bare address: it becomes a link with the address as its text (toast with Undo and Keep as text). Anything else pastes as before.
  • Allowed addresses: http, https and mailto only. Anything else (javascript:, data:, file:) is refused with "Only http, https and mailto addresses can be linked." and nothing is inserted.
  • Stored as Markdown [text](address), so it survives save, reload, Find updates and the plain file. Work-item chips, people and [[note]] links are separate and untouched.

Where it works

  • Notes and Current state (the rich editors, which already store Markdown): all four ways in.
  • Plain-text fields (the item panel's fields, Prep's notes): decision needed. They store plain text, so a link there would be saved as raw [text](address), and tables, reports, Excel and search would show it raw. My recommendation: do the rich editors first; for the plain fields, only auto-link pasted addresses in the display (no editing control) until the reports and exports can show a link.
  • Client reports and anything sent outside: a link is text plus an address; the existing client-safe checks run on the words, and the address is shown in full in the preview so nothing hidden goes out.
  • Desktop and 900px only; keyboard: the popover is a small dialog, Tab moves through its fields, Esc closes and returns to the text.
