What happens when you press Save agenda

  • The page writes one file into the project's Agendas folder, named YYYY-MM-DD Meeting title agenda.html, from the prep record. It is Internal, self-contained and prints cleanly. The live server writes it, not Claude.
  • First save only, if the folder is in OneDrive and may be shared: asked once.
  • A file creaite didn't write, or that you edited, is never overwritten: the new one gets a number. Its own unchanged file is replaced after a copy to backups (Undo).
  • The page stays open and editable; the peek and Today's popup now offer Open agenda; Files lists it under Agendas.

Editing it again, and the peek

  • Edit in creaite (top of the agenda page) or Prepare again / Open the prep page reopens the prep page from the record, with the warm banner: save again to replace the file. Items show their current state, so changes since the save are visible.
  • The item peek (my reading of "the peek for work items"): pointing at an ID or row shows a small card with status, owner, dates, latest update and source; Open launches the existing work-item peek panel. On the saved file the card is a snapshot "as at" the save time. If you meant the existing Sneak peek (the source text inside the item peek), tell me.
  • Rules kept: never sent; confidential meetings and notes handled as before.
