The left rail: options

Four versions of the same rail so you can compare them. 0 is today's icon-only rail. A, B and C add the fixes from the research: labels you can see, a clear active page, waiting counts in the accent colour (red only for problems), destinations grouped, shortcut hints, 44px targets, and flyouts on Projects, Work and More. Click an item to make it active; point at Projects, Work or More (after about 0.2 s) for its flyout; in 0 and B/C-collapsed point at an icon for its tooltip (after 0.4 s).

What each option changes

  • 0 · Today's rail: icons only, red badges on both Review and More, a pill behind the active icon, tooltips.
  • A · Expanded with labels: icon, label and a faint shortcut hint on one line; a tonal pill, bold label and left bar for the active page; counts as accent pills; a thin separator before More; the wordmark on top. Widest (224px); best for reading.
  • B · Collapsed, label under icon: 76px, Material's rail pattern: each icon has its word beneath. Narrow and still readable; the collapsed state for A.
  • C · Icons, open on hover: stays 56px; pointing at it for 0.2 s opens the labelled version over the page (no page shift). Saves space; hidden until you point.

My recommendation

  • A by default on wide screens, B when you collapse it (instead of icon-only), so the labels are always visible. C only if you want the most page room.
  • Counts: Review shows its waiting count in the accent colour; More shows "1" in amber with what it holds on hover ("Health: 1 problem"); red is kept for the live-server alert.
  • Flyouts: Projects (active projects by name with health dots), Work (Actions, RAID, Decisions, All items) and More (its items), using the shared hover delays.
  • Targets 40 to 44px, focus ring never clipped, shortcut hints shown (G then the letter), contrast checked in light, dark and forced colours.
