# Sample minutes for testing in creaite

Fictional meetings (no real names), to try the minutes flow in your own creaite. Add them to Intake, process them, then open the minutes in Review.

## Files
- `2026-10-20 Pilot readiness review.vtt`: a transcript with a decision, an issue, a risk, five actions and a loose follow-up.
- `2026-10-20 Supplier checkpoint.vtt`: a short transcript with one decision and two actions.
- `2026-10-19 Budget review minutes (from Lena Park).txt`: minutes written by someone else; creaite should check them for work items only and draft no new minutes.

## Steps
1. In creaite open **Intake** and use the file chooser (Upload files) to add the three files.
2. A transcript should show **Transcript** and **Make minutes** (2.6: an icon button, Add files); the .txt should show **Minutes** and **Find work items**. Pick a project for each (the project guess may say "Not sure").
3. Press **Process**. When done, open **Review**.
4. On a transcript's minutes row (a draft creaite made itself) press **Open draft**: it should open **inline** as a page under Review, not in Word. If it opens in Word, tell Natasha which file and which button.
5. To test #261, reject every item on one minutes row, then press **Approve** on the minutes.
