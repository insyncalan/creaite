# creaite 2.0.0

"Notes." Each project now has its own notes: plain Markdown files in the engagement's `08 Notes` folder, written in one editor that every text field in creaite now shares. Press ⌘⇧N (or N) on any page and a note opens at the right without leaving it; **Find updates** on a note turns what it says into tracker changes you tick and apply, with Undo. Select any text and press **AI** for a rewrite you accept or ignore. Nothing in a note reaches the tracker until you say so, and ask creaite can read your notes without an approval card.

## Before you update

- **A full release**, not a pre-release, so "update creaite" finds it with no version named. **No schema change and no migration.**
- **A new folder, made on first use** (BL-301): each engagement's notes go in `08 Notes` (in the vault's own layout, `projects/<folder>/notes/`), and the portfolio's and Unfiled notes in `_Portfolio/08 Notes`. Pictures added to a note go in `08 Notes/_images/`. Nothing is made until the first note; a new project gets the folder with its others, even if your skeleton lacks it. Notes are listed in Files as their own folder, not as documents.
- **One new setting, added with its default** (Settings › Advanced › Folders and OneDrive): `locations.folders.notes`, **Notes folder**, `08 Notes`. Every existing value is kept.
- **The search index is rebuilt once** (index version 2), the first time search runs after the update, so notes are found (kind `note`). It may take a little longer that once.
- **The guard changes in one agreed place: notes are not outside content** (BL-301; Alan, 15-10-2026). With the projects in OneDrive, reading anything there used to mark an ask creaite run as having read outside content, so a later change waited on the approval card. Now reading one of your notes (a `.md` file directly in a project's or the portfolio's notes folder) marks nothing. A note's pictures (`_images/`, even a `.md` there), a file in a subfolder of the notes folder or one that isn't `.md`, a search over the whole notes folder, a link named like a note (judged by what it points at), and transcripts, documents and `inbox/` still mark, as before. The hook and the live server judge it the same way (`reach.read_reason`, `reach.is_note`; `notes_exempt` in `OUTSIDE_CONTENT`). No permission rule, deny list or never-list change.
- **Also in the guard, agreed:** `edit_ai.py` joins `reach.SCRIPT_COMMANDS` as read commands only (`context`, `result`, `options`; it writes nothing). Two new run kinds, `notes-find` (Find updates) and `edit-ai` (AI on selected text), run Claude with **no tools at all**, so Claude sees only the text it is given. Renaming a note (`/api/notes/rename`; Alan, 14-10-2026) issues its own one-time approval for exactly that one move, only when the note and its new name are each ordinary, and never after outside content in an ask creaite run.
- **A note's changes are ordinary file changes** (BL-141): Alan's own notes, made at once through `filechange.py`, backed up, logged and undoable (Activity › What ask creaite changed). Drafts as you type are kept in `system/staging/drafts/notes/`, and so go in the daily backup zip (Alan, 15-10-2026).
- **Quick capture is retired** (FR-71; BL-301 C). Intake's Quick capture form, `/api/capture` and its chips are gone; the capture drawer replaces them. Quick notes saved before stay in their project's `minutes/`, and cx-minutes still processes them.
- **A new bundled library: Tiptap 3.31.3** (BL-301 A), the editor, as one minified ES module in `system/templates/vendor/tiptap/` (`tiptap.module.js`), with ProseMirror, `@tiptap/markdown`, marked and linkifyjs inside it. Every bundled package is MIT-licensed; each one's own licence file is in `system/templates/vendor/tiptap/licenses/`, and `manifest.json` records every package's version, tarball SHA-256 and licence and the SHA-256 of every file in the folder. Nothing is fetched or built at run time (NFR-12).
- **creaite's rules change** (`system/creaite-rules.md`, replaced by the update): Approval before writes names the Find updates panel as a place you approve; the folder map gains the notes folder, `folders.notes`, `notes-sent.json` and the note templates; Dashboard editing gains One editor, Notes, Find updates and the capture drawer; Marked runs gains the notes exemption; Project documents gains "Notes are passive until Find updates".
- **No new health check.**
- **To install:** say "update creaite". With `gh` signed in, creaite fetches the zip itself; without it, download the zip into `system/releases/` first.

## What's new

### A. One editor

- **One editor everywhere text is changed in place** (BL-301 A). Current state, the item panel's text fields and Prep's notes and questions now share one editor, Tiptap, with Undo and Redo (⌘Z, ⌘⇧Z) in each. Opening and saving a Current state changes nothing: only what you edit is rewritten, byte for byte otherwise, and no editor switched over until its round-trip check passed. Plain-text fields stay plain text. The Draft email preview is unchanged for now (its styled HTML and table are what Outlook pastes), pending your decision.

### B. Notes on the project page

- **Overview and Notes tabs** (BL-301 B): each project has them, and the portfolio has its own notes (Projects › Portfolio notes). The list (search, Pinned, Recent) folds away with « or ⌘\ and stays folded.
- **An open note is editable at once and saves itself:** a draft as you type, the file through creaite's backed-up, undoable file changes when you leave it or after 30 seconds, with **Saved** in its header. If the file changed outside creaite, it isn't overwritten: your draft is kept.
- **Four templates:** Blank, Stakeholder, Lessons learned, Working session. `[[` links a note, `@` a person, `#` a work item (a live chip), `/` inserts. A click on a link or chip opens it; ⌥-click edits inside it (Alan, 15-10-2026).
- **What connects:** the right column shows the notes that link here, the linked work and the people; an item's panel says which notes mention it.
- **Pictures, renaming and the meeting's details:** an **Image** button adds pictures (PNG or JPEG, 2 MB at most, kept in `08 Notes/_images`); changing a note's title renames its file, and `[[links]]` to it in your other notes follow; a Working session's date and who it was with can be changed in its header.
- **Plain files:** notes are Markdown files with a small front matter, listed in Files and found by search; internal, never in a client report.
- **Margin ticks** on lines already sent to the tracker (moving: `v20-ticks`).

### C. A note from any page

- **The capture drawer** (BL-301 C): press ⌘⇧N, or N when you aren't typing (in an ordinary Chrome tab ⌘⇧N opens an incognito window, so N is there too), or ⌘K "New note", and a note opens at the right without leaving the page.
- **The project is guessed** from the project register, with the reason ("guessed from “Omar Ali”"); change it if it's wrong, or leave it Unfiled (the portfolio's notes).
- **Done** saves it in the project's `08 Notes` folder (backed up and undoable); **Done and find updates** opens it in Notes with Find updates; a recent note at the drawer's foot opens in Notes. **Confidential**, off unless you turn it on, keeps it out of client reports and of what search gathers for Claude, and Claude reads it only if you say yes (out of the Prep page run in code too: moving, `v20-confidential-prep`).
- **Note for this meeting** under a meeting on Today starts a Working session note with its date and who was invited, and "note: …" in ask creaite saves one the same way (the page sends it, never the model).
- It replaces Intake's Quick capture; quick notes saved before stay where they are.

### D. AI on selected text

- **Select, then AI** (BL-301 D): select text in Current state, an item's title or longer fields, Prep's notes or a note, and press **AI** (or Alt+/): Rewrite clearly, Shorter, Longer, Make it executive, Fix spelling and grammar, and more where they fit, or say what you want.
- **Claude sees only that text** and the project's name, people and open item IDs, with no tools. The answer is a suggestion with a check on dates, numbers, names and item IDs; nothing changes until you press **Accept**, and ⌘Z undoes it. A one-line field stays one line; a confidential text asks first. Make it executive for the whole Current state is now in the editor's **AI** menu.
- **Make this an action, a risk, a decision or an update** on one selected line of a note runs Find updates on that line only (moving: `v20-ai-select`'s Notes wiring).

### E. Find updates

- **From a note to the tracker** (BL-301 E): ✦ Find updates on a note opens a panel beside it with the tracker changes its new lines state, grouped New, Updates, Milestones and Project information, each numbered to match its line in the note.
- **What starts ticked:** routine rows. New risks, decisions, milestone moves, health and memory lines start unticked; a hedged line ("probably", "to confirm") never moves a milestone and gets a confirm action instead.
- **You approve here:** click a row to edit it; **Apply** writes the ticked rows as one change through the tracker's one writer, with **Undo**; **Save for later** sends them to Review instead.
- **Only what's new:** running it again looks only at new or changed lines; what each line became is kept beside the note (`system/staging/notes-sent.json`: line numbers, fingerprints and item IDs, never text). Claude sees only those lines, with no tools; a confidential note asks first.

## Check once by hand

1. **After updating:** say "what version is creaite?": 2.0.0. `system/scripts/run doctor.py` passes. Settings › Advanced › Folders and OneDrive shows **Notes folder**, `08 Notes`.
2. **A note:** on a project's Notes tab, make a note from the Stakeholder template, type a line with `@` a person and `#` an item, leave it: **Saved**, and the file is in `08 Notes`. Change its title: the file is renamed, and a `[[link]]` to it in another note follows.
3. **From any page:** press ⌘⇧N on Work, then N on Today (not in a field): the drawer opens each time, with a guessed project and its reason. **Note for this meeting** on Today fills in the meeting's title, date and attendees.
4. **AI on a selection:** select a sentence in a Current state, AI › Shorter, **Accept**, then ⌘Z: it is back as it was. Open and save another Current state unchanged: the file is unchanged.
5. **Find updates:** on a note with an action and a new risk in it, ✦ Find updates: the action is ticked, the risk isn't. **Apply**, then **Undo**. Run it again: only new lines are offered.
6. **ask creaite reads a note:** with the projects in OneDrive, ask "what does my latest note on Falcon say?" and then ask for an ordinary change: no approval card. Ask about a transcript first instead: the card comes back.
