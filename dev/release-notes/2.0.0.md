# creaite 2.0.0

## Changes

- **One editor (BL-301 A).** Current state, the item panel's text fields and Prep's notes and questions now share one editor, with Undo and Redo (⌘Z, ⌘⇧Z) in each. Opening and saving a Current state changes nothing: only what you edit is rewritten. The Draft email preview is unchanged for now.
- **A note from any page (BL-301 C).** Press ⌘⇧N, or N when you aren't typing (in an ordinary Chrome tab ⌘⇧N opens an incognito window), or ⌘K "New note", and a note opens at the right without leaving the page. creaite guesses the project from the project register and says why ("guessed from “Omar Ali”"); change it if it's wrong, or leave it Unfiled. It is kept as a draft as you type; **Done** saves it in the project's `08 Notes` folder (backed up and undoable); **Confidential** (off unless you turn it on) keeps it out of prep pages and client reports, and Claude reads it only if you say yes. **Done and find updates** opens it with Find updates. **Note** under a meeting on Today starts a Working session note with its date and who was invited, and "note: …" in ask creaite saves one the same way. It replaces Intake's Quick Capture; quick notes saved before stay where they are.
- **Notes on the project page** (BL-301 B): each project has **Overview** and **Notes** tabs, and the portfolio has its own notes (Projects › Portfolio notes). The list (search, Pinned, Recent) folds away with « or ⌘\ and stays folded; an open note is editable at once and saves itself (a draft as you type, the file through creaite's backed-up, undoable file changes when you leave it or after 30 seconds), with **Saved** in its header. Four templates (Blank, Stakeholder, Lessons learned, Working session); `[[` links a note, `@` a person, `#` a work item (a live chip), `/` inserts. The right column shows the notes that link here, the linked work and the people; an item's panel says which notes mention it. Notes are plain Markdown files in each engagement's `08 Notes` folder, listed in Files and found by search; internal, never in a client report.
- **Find updates in a note** (BL-301 E): ✦ Find updates on a note opens a panel beside it with the tracker changes its new lines state, grouped New, Updates, Milestones and Project information, each numbered to match its line. Routine rows start ticked; new risks, decisions, milestone moves, health and memory lines start unticked; a hedged line ("probably", "to confirm") never moves a milestone and gets a confirm action instead. Click a row to edit it; **Apply** writes the ticked rows as one change with **Undo**, **Save for later** sends them to Review. Running it again looks only at new or changed lines. Claude sees only the new lines, with no tools; a confidential note asks first.
- **Notes, three gaps closed** (BL-301 B): an **Image** button adds pictures to a note (kept in `08 Notes/_images`); changing a note's title renames its file, and links to it in your other notes follow; a Working session's date and who it was with can be changed in the note's header.
- **AI on selected text (BL-301 D).** Select text in Current state, an item's title or longer fields, or Prep's notes, and press **AI** (or Alt+/): Rewrite clearly, Shorter, Longer, Make it executive, Fix spelling and grammar, and more where they fit, or say what you want. Claude sees only that text and the project's name, people and open item IDs, with no tools. The answer is a suggestion with a check on dates, numbers, names and item IDs; nothing changes until you press Accept, and ⌘Z undoes it. Make it executive for the whole Current state is now in the editor's **AI** menu.
