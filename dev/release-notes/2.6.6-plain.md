# What's new in creaite 2.6.6 (plain words)

2.6.6 contains all of 2.6.5. The headline: the screens are calmer and plainer (Alan's 17 design decisions), the mail and Teams check says truthfully what it is doing while it runs, and a project code in a meeting's title now always wins over what creaite remembered for that series of meetings.

## What changed for you

### Mail and Teams check
- **A true line while it runs.** Instead of a joke, the line under the check reads "Looked in so far: Outlook mail, Teams · 3 searches, 5 items read". It names only the places the check has actually searched, in the order it reached them, and the counts grow as it works. There is no total, no "of 5" and no percentage, because creaite cannot know how much is left. The badge that shows a run in progress reads "Mail check: mail, Teams", so you can see it with the chat closed. Other chats keep their usual line. (#358)
- **It says how it ended.** "Finished. Looked in Outlook mail, Teams. Found 7 new, 4 need a project." or "Finished. Nothing new to review." If you press Stop, or it ends early, the line says so and gives what was found so far. (#358)
- **Found N counts new items only.** An update to an item you already have is not counted as new. It is read from what that check itself saved, so a change you made yourself in the meantime is never counted. (#358)
- **Close the day ticks its rows from the check's own searches.** The rows "Mail", "Teams chats" and "Teams channels" tick when a step with exactly that job has finished, and the first row not yet ticked shows as the one in progress. Its line says "Working through the sources" rather than naming one source as being read now. A mail subject or a message that happens to contain the word "Teams" ticks nothing. (#358)

### Meetings and projects
- **A project code in the title always wins.** If a meeting's title carries one project code, in square brackets in any case ("[def] Weekly sync") or as a code on its own, that project is used, even when you earlier told creaite that a series with the same name belongs to another project. Before, the remembered series won, so "[DEF] Weekly sync" could be minuted under the project you had chosen for "[ABC] Weekly sync". (#362)
- **Two different codes win nothing.** A title naming two projects says "Not sure" and offers both, whatever was remembered. A title with no code behaves as before: the remembered series is used. Your "no project" choice for a series still stands. A confidential meeting still shows no project. (#362)

### Design decisions (#341)
- **No coloured bars down the side of notes.** Tips, warnings and quotes now carry a small icon (information, alert or quote) in place of the thick coloured edge. The selected row has a line above and below instead of a bar on the left, with its tick as before. (#341, item 1)
- **Review's "what changes" line** is the same 14 px as the title; it stands out by being bold, not bigger. (item 2)
- **Projects.** The next milestone is written as 13-11-2026 (in 24 days), not written out. Evidence shows only the figures above zero, and says "Nothing flagged" when there are none. A project whose health is Not set says why and what to do next: "No update has set a health yet. Next: open the project and choose a health." Today's own project table keeps its written-out dates. (items 3, 4, 5)
- **Work.** The little half-circle and the priority bars before each title are gone. A screen reader still hears the status and priority. (item 6)
- **Intake.** A selected meeting looks the same in the List, the Board and Two panes: a soft tint with a line above and below. A file you added takes one line of facts (when it was added, its likely project, its state); what kind of file it is shows only when you need to choose. (items 7, 8)
- **Milestones.** The switch between Internal view and Client view is smaller and quieter: a soft fill and bold type for the one in use, so the view switch (Plan, Movement) remains the main control. (item 9)
- **People.** Names, projects and counts in a row are all links in one style: ordinary text with a dotted underline that turns to the accent colour when you point at it. (item 10)
- **Plain words.** "Open RAID" is now "Open risks and issues", "Flow" is "Progress over time", and "Milestone slip" is "Late milestones". The People table's heading is "Risks and issues". (item 11)
- **Cockpit.** The right-hand column (risks, decisions, warnings) is wider, two fifths of the page instead of a third, and it stacks under the left on narrow windows. (item 12)
- **Files has two ways to narrow the list**: the folder tree and Filter. The four views (All files, Latest reports, This week's meetings, Archived) moved into Filter under View, and a chip shows "View: ..." while one is on. Choosing a view clears the folder, and Clear in Filter returns to All files. (item 13)
- **The search button says "ask creaite"** in words beside its icon, so it is clear what pressing it does. (item 14)
- **Activity** has a Select all tick in the header. It ticks the changes you can see that can be undone, and leaves the others alone. (item 15)
- **Settings** no longer has the "Help and documentation" card. Help is still there: press ?. (item 16)
- **Amber** is not changed in this release. A list of every place amber is used, with a suggestion for each, is ready for you to decide on. (item 17)

## Good to know

- A dashboard tab left open from before the update gets a "reload the page" message instead of deciding anything. Reload it.
- The "Looked in so far" line is for a mail check you ask for in the chat ("check my mail"). Close the day shows its own four rows. Other chats keep their usual line.
- The count at the end of a check reads only the check's own saved suggestions. If Review cannot be read at that moment, the line says "Finished. Open Review to see what it found."
- Amber is changed in a later release, after you have chosen.
- The known leftovers from 2.6.5 are still there: a file path shows in a few places, Help still describes past days on Today the old way, and "Saved for Review" can still show above the Save bar.
- Not in 2.6.6: fetching transcripts as they appear, and the shared-database work (paused).
