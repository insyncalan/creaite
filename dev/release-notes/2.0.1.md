# creaite 2.0.1

A security patch. It narrows what the background Claude runs behind the VIP check, search and the drafting features can do, so a message or document they read can no longer make them run commands or change files.

## Before you update

- **No schema change and no migration.**
- **No new setting.** Nothing is added or moved; every saved value is kept.
- **It replaces the engine only.**
- **A full release**, not a pre-release, so "update creaite" finds it with no version named. To install, say "update creaite".

## Changes

- **The VIP check can only read Microsoft 365.** It now starts with no file, command or web tools, only the four Microsoft 365 reading tools, so it can't run commands or edit files even if a message it reads tells it to.
- **The search answer reads vault text only.** It now has only Read, Grep and Glob and no Microsoft 365 tools: it can read files in the vault, but can't run commands, edit files or reach the web. The tracker rows it needs arrive with the question, so an answer that needs more rows than were gathered may say the sources don't answer.
- **Drafting runs can't edit or write files.** Prep page, Current state, the AI drafts, Shape the meeting and the transcript checks can no longer edit or write files themselves; creaite writes the result.
- **Reply-only runs can't write files.** The Shape-the-meeting and Find-updates runs that only reply can no longer write files.

## Known, for later

These are being fixed for 2.1.0:

- **Held-run commands.** A run that has read outside content can still run some creaite staging commands. They are being restricted to read-only commands.
- **Newer built-in tools.** Built-in tools that no run needs are not yet removed one by one.
- **ask creaite's chat commands** don't yet get the same checks.
