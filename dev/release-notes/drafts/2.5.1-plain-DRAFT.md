## What changed for you

- **ask creaite no longer writes or changes your weekly or client reports.** It can still read them and answer questions about them. You write and edit reports yourself in the Reporting hub.
- **A weekly report row you left out now says "Left out".** Before, it showed an empty row with "Click to write". The eye on it brings the item back with its text, owner and due date from the tracker, and an export never has an empty row.
- **Client reports only ever use a project's own logos.** A logo that belongs to another project can no longer appear on a client report or be saved into one. A logo picture you use in a client HTML export is cleaned so it carries only what is drawn: no hidden words, links or scripts.
- **Today is quieter.** With nothing waiting, Needs attention says "Nothing needs your attention." and no longer shows a "How Today works" box. A small ? beside Close the day opens Today's help.
- **The Sweep due banner can be dismissed** with a small x, without running a sweep. It stays away for the rest of the day and comes back when the next sweep falls due.
- **You can clear Health problems.** Each problem in Settings › Health has Dismiss, with an optional reason. A dismissed problem stops counting on the side bar and moves to "Dismissed", where you can Restore it. If it changes, it comes back by itself. Faults in creaite's own engine, such as the database or write access, cannot be dismissed.
- **The Work filter panel is never cut off.** On a short list the lower fields and the Done button used to be clipped. The panel now stays in view and scrolls inside itself.
- **(Only if it lands) A Usage tab on Activity** shows what each Claude run costs and loads, over time. It counts only; it never records any text.
