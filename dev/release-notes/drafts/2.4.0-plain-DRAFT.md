# What's new in creaite 2.4.0 (plain words)

Weekly reporting is rebuilt as one place: you write the internal report and the client report side by side, and what you export looks like what you see and is saved where you can find it.

## What changed for you

- **One reporting hub for each project.** Internal, Client or Side by side, with the week chosen from a list. A Reports icon beside Files at the bottom of the project page opens it, and the two old report buttons are gone.
- **A client report only where you need one.** A cog beside Export turns the client report on or off for a project, and the setting holds for every future report until you change it. With it off, you see only the internal report.
- **The same editing in both reports.** One sheet for both, so every improvement reaches both.
- **Your logos in the header.** Click a logo's place in the report header to add or change it; the firm's logo is always there, and the client's and a partner's when you choose.
- **A tidier report page.** The section menu is small and always fully on screen; the health indicator keeps its width and its six-week strip fits it; the include or leave-out switch is an eye; and "Add from the tracker" lets you tick existing risks, issues and actions to include.
- **A free-text section, anywhere.** Add a section of your own with a heading and the full editor, move it up or down, leave it out of the export or delete it.
- **Exports look like the report.** HTML and PDF are made from the report's own "Show as exported" page, checked on the way out so nothing you left out gets in; if that is not possible you get a plain version and are told so. HTML, PDF and Word now keep the header and logos, the health block with its six weeks, the figures at a glance, the milestone timeline as a picture with its table, the full tables and the text, with dates as DD-MM-YYYY.
- **Exports are saved, and you're told where.** The message names the project's Reports folder (a link that opens it) with Show in Finder and Open. If a file with that name exists, you choose whether to add a number, rename it or overwrite it. HTML, Word and PDF all use the report's plain file name. Before a report is filed, the first HTML export is offered a numbered name so that it never gets in the way of "Approve and file"; once it is filed, exporting asks whether to overwrite the filed copy, rename or add a number. Reports always save into the project's Reports folder, so the Advanced setting "File report exports beside it" is gone (the one for minutes stays).
- **Review: each row's detail is now one line;** the owner, priority and due date show on hover and in the peek. The owner's name on the row is no longer a link.
- **Activity: the Kind button is gone;** filter by kind from the filter bar.
