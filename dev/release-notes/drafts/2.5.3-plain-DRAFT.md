# What's new in creaite 2.5.3 (plain words): DRAFT, started 20-10-2026, firmed up from the landed list at the cut

A defects release: a quieter project page, a simpler Delete note, tidier logs, and one name for the archive folder. Written only from what lands; anything not on the cut's list is struck.

## What changed for you

- **The project cockpit no longer has a Reporting card.** The Reporting card ("Reporting · this week", the weekly and client report rows and Open reporting) is gone from the project page; reports are in the Reporting hub, one click from the project. (#254)
- **Delete note needs no approval card.** Pressing Delete note on the Notes tab is the approval: the note moves to the archive at once, and Undo brings it back. (#255)
- **The archive folder has one name, "99 Archive".** It replaces `_Archive` and the older `zz Archive`, so it sorts last in OneDrive beside `99 System`. (#252) creaite does not rename your existing archive folders: the old names keep working for one release, and you rename them yourself when you like.
- **Tidier logs.** The sweep's log line no longer holds names, and a failure that used to be logged without its cause now says why. Nothing you see changes. (#253)

## What you need to do

Nothing is required. To use the new name on your existing archives, rename those folders to "99 Archive" yourself; until then the old names still work.
