# What's new in creaite 2.6.11

## What changed for you

2.6.11 contains all of 2.6.10. The headline: a meeting you processed from a file no longer waits in Intake's Arrived list.

### Intake
- **A meeting you processed from a file leaves Arrived.** When you drop in or upload a meeting's transcript and process it, its calendar meeting no longer stays in Arrived as "Transcript ready", and Intake shows one row for the meeting. If two meetings on the same day have the same title, creaite does not guess and leaves both as they were. Someone else's minutes are never linked this way. (#389)

- Update from the release zip as usual.
- Reload any dashboard tab that was open before the update.
- Process one meeting from a file and look at Intake once, to see it leave Arrived.

### Good to know
- **A file processed under another title or another day stays in Arrived**, as before. For example, a late-evening meeting whose transcript is dated the next day is not linked.
- **Rejected minutes still mark the meeting as processed** when its transcript was filed, as they always have.
