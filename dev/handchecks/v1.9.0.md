## Setup

Run on a scratch vault: never the live vault, and never the development repository itself (the tests read its sample data).

1. **Main.** In a clean checkout of `origin/main`: `VERSION` says 1.9.0 and `git log --oneline origin/main` shows each branch above merged.
2. **The zip and a vault** (from the repository root):
   ```
   HC=$(mktemp -d -t creaite-hc)
   python3 dev/tools/build_release.py --out "$HC/zip"
   python3 -I system/scripts/update.py new-vault "$HC"/zip/creaite-*.zip "$HC/vault"
   touch "$HC/vault/.creaite-dev"        # keeps the VIP check and the session-start sweep off
   ```
3. **Sample data:** `mkdir -p "$HC/vault/dev/tools" && cp dev/tools/demo_data.py "$HC/vault/dev/tools/"`, then in `$HC/vault`: `python3 dev/tools/demo_data.py load`. This gives four fictional projects (FAL Falcon Data Platform, ORX Orbit Customer App, MER Meridian Contact Centre AI, TID) and a week of meetings from Monday to two days ahead.
4. **Registers and you:** add FAL, ORX, MER and TID (code, name, folder) to `projects/_portfolio/project-register.md`, and their owners to `people-register.md` (one with no email). In Settings, set your name to Alan Carter and your domain to brightwater.example. Hand edits are fine in a scratch vault.
5. **A longer calendar** (stand-in for cx-sweep's Outlook read, for BL-293 and BL-287): write `$HC/cal.json` as `{"days": {"YYYY-MM-DD": [{"id": "hc-1", "start": "10:00", "end": "11:00", "title": "FAL Steering committee", "where": "Microsoft Teams Meeting", "teams": true, "private": false, "organiser": true}]}}`, with days up to seven days ahead, including one meeting three working days out and one with `"private": true`. Then `system/scripts/run sweep.py calendar "$HC/cal.json"`.
6. **Stand-in Claude:** from the repository root, `python3 -c "import sys,pathlib,types; sys.path.insert(0,'dev/tests'); import drafts_fake; print(drafts_fake.install(types.SimpleNamespace(root=pathlib.Path('$HC'))))"` writes `$HC/fake_claude.py`. Where a check needs another reply, it names the test whose stand-in to copy into `$HC` instead.
7. **Start:** in `$HC/vault`, `CREAITE_PORT=8990 CREAITE_CLAUDE="$HC/fake_claude.py" system/scripts/run live_server.py`. Open the address it prints in Chrome (not Safari). Ctrl+C stops it.
8. **Chrome for the cross-cutting checks:** DevTools › Rendering (`prefers-reduced-motion: reduce`, `prefers-color-scheme: dark`, `prefers-contrast: more`, forced colours). Device toolbar › Responsive at 320 px wide. A theme from Settings.
9. **Reset:** Ctrl+C, `rm -rf "$HC"`, then steps 2 to 7 (about two minutes). Lighter: `python3 dev/tools/demo_data.py purge && python3 dev/tools/demo_data.py load` in the vault. A single change: Undo, or `system/scripts/run tracker.py undo`.

Dates in the sample data follow today's date. A check that adds days (such as "+3d") can fall on a weekend; run on a weekday.
