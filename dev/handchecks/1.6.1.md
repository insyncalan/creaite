## Failures

### 18. A refused wrapper command is described as "run run"

- **What happened:** the stand-in had ask creaite run `system/scripts/run tracker.py read actions > actions.txt`, which was refused, and then carry on another way. The chat line read: "I tried to run **run**, which isn't one of creaite's scripts. Only creaite's own scripts run here, so I'll do it with one of them."
  - The fold-out, the absence of ⚠ (the run recovered) and the absence of a "Refused:" line were all correct.
- **What was expected:** "I tried to save the output of the tracker (tracker.py) to a file…". That is the sentence the `python3 system/scripts/tracker.py … > …` spelling gets.
- **Cause:** `refused_plain` and `refused_shape` in `live_server.py` find the script with `system/scripts/([a-z0-9_]+\.py)`. That pattern doesn't match the `system/scripts/run tracker.py` form, which BL-237 makes the usual one.
  - The debug log's shape is wrong in the same way: "a command that isn't a creaite script".
  - The same pattern is still on main.
- **Scope:** this checks how the page displays the refusal, using stand-in stream events. The real guard was not exercised.

### 24. "Apply edits automatically" is named `autoApply`

- **What happened:** Chrome's accessibility tree gives the Settings › General › Saving switch the name **"autoApply"**, from `aria-label="autoApply"` on `input[data-k=autoApply]`.
  - Every other field checked has its proper name. That covers Files' four filters, the vault search and the other 11 fields in Settings › General.
- **What was expected:** the row's own label, "Apply edits automatically".
- **Closed by Alan (13-10-2026):** the VoiceOver pass itself.

### 26. "update creaite" can't fetch the newest release

- **What happened:** `update.py fetch` with no tag fails with "gh couldn't download the release (release not found)" even when gh is signed in.
  - Every creaite release on GitHub is marked **Pre-release**, and `gh release download` without a tag asks for the "latest" release, which never includes pre-releases.
  - `fetch v1.6.1` (a named tag) works.
- **What was expected:** it fetches the newest release and waits for Alan's yes.
- **What did pass:**
  - Signed out (an empty `GH_CONFIG_DIR`), it says so and points to the hand download.
  - Help › How do I… › Update creaite says the same.
- **Closed by Alan (13-10-2026):** the "update creaite" conversation itself (a model run).
