## Minutes view

1. **Export groups (#330).** Open approved minutes, Export. Two headed groups: Shareable (Word, PDF, HTML, follow-up email) first, then Internal (the same, each marked Internal). Export Shareable Word: the file name ends "(shareable)"; no Sensitive item row appears; the text near the menu says "Sensitive items left out; check the Updates text".
2. **Shareable on a draft (#330).** Open minutes you have not approved. The three Shareable files are greyed out with "Approve the minutes first"; the Shareable email still works and shows "Draft: check before sending". The Internal files work.
3. **Word header (#331).** Open the Internal Word and the Shareable Word for the same minutes. The title block shows the project name with the client, the When line and the attendees, the same as the page and the PDF.
4. **File the minutes (#324).** Press Approve minutes on a meeting. A box says the project and folder in words and shows the name in a field. Esc closes it and files nothing, focus returns to Approve minutes. Press it again, change the name, Approve: a note says where they went; Open file opens them; Open folder opens the folder.
5. **A taken name is numbered (#332).** Approve a second meeting with the same title and day. It is filed as "Title (2)" with its transcript; no "stopped" error.
6. **Open folder on Approved this week (#326).** A Done row has Open folder; for a moved or missing file it says so in words and shows no path.
7. **Keyboard (#302).** In the minutes view press J: a row is chosen. J and K move; Y, M, N change the Track choice and the counts and Approve label follow; E edits; S shows the source; Z undoes the last choice, including one made by clicking. Typing in a field takes none of these keys. Nothing on screen advertises them.
