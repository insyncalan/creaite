### #239 Client output as one checked snapshot
A vault of its own: FAL's weekly report is approved first, then a client draft saved with a marker sentence, as the hub asks.
1. Approve a client report → creaite freezes a checked copy of it; the approval is recorded; the Word, HTML and PDF client files are all made from that one copy.
   - Test: `test_v252.py::Client239.test_c01_approve_freezes_a_checked_copy_and_every_export_is_made_from_it` (the `.client.json` beside the filed report, its SHA-256 in `client-snapshots.json`, each format holding the approved words, words edited into the filed file never exported; then `test_client_output_step2`'s snapshot tests and `test_client_output_step3`'s cx-client-report route, called). PDF is skipped when Chrome headless cannot make one.
2. A client export made from a page posted with the request: the posted page is never used (the saved, checked copy is).
   - Test: `test_v252.py::Client239.test_c02_a_posted_page_is_never_used` (`page_ignored` in the answer, none of the posted words in the file; then step 1's and step 2's posted-page tests).
3. A client report whose file says it is internal (or has no kind) is still treated as a client report.
   - Test: `test_v252.py::Called239.test_c03_a_client_report_is_always_a_client_report` (`test_client_audience`, `test_client_gate`).
4. The header, the logos and the audience on a client export come from the project at the time of export, not from the report file.
   - Test: `test_v252.py::Called239.test_c04_header_logos_and_audience_come_from_the_project` (`test_client_audience`'s header tests, step 1's unticked logo, `test_client_gate`).
5. Only the project's own logo files and the report's own pictures can be drawn; a logo or picture path from another project, or a hard-linked file, is not drawn; extra fields in the report are dropped.
   - Test: `test_v252.py::Called239.test_c05_only_own_logos_and_pictures_and_extras_dropped` (steps 1 to 3, `test_client_audience`).
6. Words hidden in look-alike letters or escapes (for example a Cyrillic letter inside a hidden item's word) are caught: the export is refused or the item is left out, as for a plain hidden word.
   - Test: `test_v252.py::Called239.test_c06_look_alike_letters_are_caught` (step 1, `test_client_gate_late`).
7. Another project's words and owners in a client report are caught in the same way.
   - Test: `test_v252.py::Called239.test_c07_another_projects_words_are_caught` (step 3's gap B, `test_client_audience`).
8. The minutes export refuses a client report.
   - Test: `test_v252.py::Client239.test_c08_the_minutes_export_refuses_a_client_report` (Word and HTML refused, nothing made; then step 1's minutes-route tests and `test_client_audience`).
9. A typed export name that matches another report's filing name does not overwrite or claim it (it gets a number).
   - Test: `test_v252.py::Called239.test_c09_a_typed_name_cannot_claim_a_filing_name` (`test_export_rename_name`, `test_client_audience`).
10. A client report built by the older Word route goes through the same checked snapshot.
    - Test: `test_v252.py::Called239.test_c10_the_older_word_route_is_gated` (step 3's Word, template and migration tests).
11. **Live only, with Alan:** export a real client report as Word, HTML and PDF with the real logo → it looks as before and nothing hidden or internal is in it.
    - Test: none (`LIVE_ONLY[11]` in `test_v252.py`); run by hand.
