## Setup

1. **The branch.** In a clean checkout of `release-210` (or `origin/main` once merged): `VERSION` says 2.1.0.
2. **The zip and a vault** (from the repository root):
   ```
   HC=$(mktemp -d -t creaite-hc)
   python3 dev/tools/build_release.py --out "$HC/zip"
   python3 -I system/scripts/update.py new-vault "$HC"/zip/creaite-*.zip "$HC/vault"
   ```
   Then `touch "$HC/vault/.creaite-dev"` (keeps the VIP check and the session-start sweep off).
3. **Sample data:** `mkdir -p "$HC/vault/dev/tools" && cp dev/tools/demo_data.py "$HC/vault/dev/tools/"`, then in `$HC/vault`: `python3 dev/tools/demo_data.py load`. Add FAL, ORX, MER and TID to `project-register.md` (FAL's signals including the word "Falcon") and their owners to `people-register.md`.
4. **A transcript.** Write `$HC/vault/inbox/<today, YYYY-MM-DD> FAL Steering committee.vtt`:
   ```
   WEBVTT

   00:00:05.000 --> 00:00:14.000
   <v Alan Carter>Morning all. Falcon steering: access, the security review and go-live.</v>

   00:00:14.000 --> 00:00:26.000
   <v Lena Fischer>The security review of the ingestion pipeline is done, signed off yesterday.</v>

   00:00:26.000 --> 00:00:40.000
   <v Alan Carter>Good. Lena, can you book the UAT environment by Friday?</v>

   00:00:40.000 --> 00:00:52.000
   <v Lena Fischer>Yes. One risk: the vendor's team is short in November, so the cut-over could slip.</v>

   00:00:52.000 --> 00:01:06.000
   <v Rashid Al Suwaidi>We agree to run domain 3 on masked data for UAT. I'll confirm the pilot site by end of month.</v>
   ```
5. **Start:** in `$HC/vault`, `CREAITE_PORT=8990 system/scripts/run live_server.py`. Open the printed address in Chrome. Ctrl+C stops it.
6. **The Console helper** (DevTools › Console, on the dashboard's page), for the checks that have no screen yet:
   ```
   const T = JSON.parse(document.getElementById("data").textContent).token;
   const m = (path, body) => fetch(path, {method: "POST", headers: {"Content-Type": "application/json", "X-Creaite-Token": T},
     body: JSON.stringify(body)}).then(r => r.json()).then(x => (console.log(x), x));
   ```
7. **Reset:** Ctrl+C, `rm -rf "$HC"`, then steps 2 to 6. A single apply: Undo, or `system/scripts/run tracker.py undo`.
