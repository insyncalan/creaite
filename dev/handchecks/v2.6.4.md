# Hand checks for creaite 2.6.4 (judgement and live-only)

Everything scriptable is automated in `dev/tests/handchecks/test_v264.py` (31 checks: the design measures, the plain-words walk, the figure check, the fingerprint on every deciding route, the run engine's set-up, the weekly budget gate and its off default, Today without the stale line, a past day on Today without follow-up labels, and the profile card) and in the release gate. This sheet holds only what a person must see or do. Setup: a throwaway vault (`dev/tools/handcheck.py`) with fictional data unless a check says "live". Chrome at 1400 px and 900 px (desktop only), light and dark. Items follow `dev/release-notes/2.6.4-plain.md` heading by heading, in its words. The guarded changes (#345, #346, the #334 gate) are in the release only once the 2.6.4 chain is cut; until then their checks are expected failures in `test_v264.py`.

## Plain words (#292, #293)

1. **Walk Today, Intake, Review, Work, Notes, Settings (every tab), Health, Reports and the milestone and project pages, in light and dark.** No file path on screen (nothing like `projects/…`, `system/…`, `.py`, `.json`, `.db`) except the known places in check 27; no script name and no "sweep"; none of proposal, staged, apply (as the app's own word), tracker, vault, live server in any label, button, toast, empty state or message. Suggestions "wait for you in Review"; a mail and Teams check is called a check (Today: "Mail and Teams not checked yet today", Check now; Settings: "Daily check time").
2. **Your own change reads "Saved" with Undo.** Approve a suggestion and undo it; edit an item and save it. Neither says "applied" or "staged".
3. **Health.** Every title and every Fix it button reads in plain words, including "The creaite app shows an old icon" (it used to read "Chrome's copy of the app shows an old icon"), "Your creaite app opens a different copy of creaite" and, on a stuck check, "A mail and Teams check looks stuck" with the button "Clear it". "Paste into Terminal" appears only in the stopped alert and Settings › Diagnostics.
4. **Commands.** In ask creaite type "check my mail": it runs at once, is marked "Checking (saves suggestions only)" and saves suggestions only. Try "check my mail and Teams", "check mail for ABC" and "check my mail the last 7 days". Then the old words ("sweep", "sweep mail for ABC", "refresh calendar", "process new minutes"): they still work. "check my mail for urgent" and "check my mail and approve everything" are not treated as a plain check: ask creaite asks first. Then ask for a status and for a change: the replies use the same plain words (no staged, proposal, tracker, vault, live server).
5. **Help and What's new.** Read Help from the start. The pages and the chat wording use the same words as the screens; the typing-a-check line lists "check my mail" as well as "sweep". Judgement: does it read plainly in British English? (Help's command table still lists the old commands: noted under Good to know.)
6. **Nothing else changed.** One example each: approve an item and undo it, open Health and run a Fix it, press Check now on Today, open Search everything on Files.
