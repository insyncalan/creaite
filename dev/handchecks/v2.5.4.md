## Checks

### Scripted (the numbers are the test's)
1. **#276** A "Replied" line and a "nothing for you" line on Today each offer Seen; pressing it clears the line.
2. **#277** The match check refuses a document whose project code is a list (a clear message, not a failure); ordinary documents are checked as before.
3. **#279** Prep on a meeting that no project matches opens the page, with a Project picker (the projects, plus "No project (general meeting)"); choosing one loads the page and the choice is remembered; old research done for another project shows "The research was done for X. Press Refresh research"; a remembered project that no longer exists counts as not chosen.
4. **#280** A decision is never saved with a field it doesn't have; one bad item doesn't block the rest: an invalid item goes back to pending with "Can't be saved as it is: <reason> · Edit it or reject it" and Approve off (once the item is fixed in the peek it becomes approvable again); held minutes with a missing transcript show "Held: transcript no longer in the inbox" with Approve without the transcript / Discard / Edit it; a save of a work item never fails because of an older item.
5. **#281** The Draft email preview is user-resizable in every Draft email window (decision chase, action chase, update request, person page, Review): drag the grip in the bottom corner taller and shorter at 1400 and 900 px; the text and table reflow; a drag that ends below the dialog does not close it.
6. **#282** Minutes exports (Word, PDF, HTML, follow-up email) say "Actions", not "Action Items".
7. **#284** There is no "?" button in Today's day band; Close the day is unchanged; the ? key still opens "Help · Today".
8. **#285** The project page and the Milestones page have no project dropdown, no ‹ › arrows and no [ ] keys; every project is reachable from the Projects list or search, and its Milestones from the project's Milestones card and the address `#milestones=CODE`.
9. **#286** Hovering the type icon of each kind (Action, Decision, Risk, Issue, Assumption, Dependency, Milestone) names it, on Today, Work, Review, search, the project page, the person page and Week ahead, including the Milestones page and the project's Milestones card.
10. **#287** The health Change menu (On track / At risk / Off track) is a compact menu inside the window, not clipped at either edge or under the side bar, in the Claude and Retro Arcade palettes; all three options read; Esc closes it.
