## Checks

### Top bar and side bar

1. Scroll down any page (Today, Work, Files, Review, a report) → the top bar (search or jump, ask creaite, theme switch) goes; scroll back to the very top → it returns. On the Weekly report the slim bar's buttons never bring the header back.
   - Test: no test found. Measurable (header height 0 when scrolled, restored at top); the feel is judgement.
2. Customise sidebar offers Small, Medium, Large; Small equals today's look; the choice is remembered after a reload; the existing Customise features (order, hide) still work.
   - Test: no test found. Measurable (icon size per setting, expanded rail 188/204/220 px); judgement for sharpness: icons not stretched.

### Files and Today

3. Files shows four view pills and a Filter button beside them on the same line; the Filter opens the filter bar; the date filter opens a popup calendar.
   - Test: no test found. Judgement against `files-navigation-v2-mockup.html`.
4. Today's Intake and Review is one quiet line, not a list, and opens Review/Intake when clicked; with nothing waiting the line is absent.
   - Test: no test found. Judgement.
5. When the last sweep is before 07:00 today and it is later than 07:00, Today shows "Sweep due since 07:00" with a Run sweep button; the button runs the sweep; the banner goes when the sweep finishes.
   - Test: no test found. Needs the stand-in Claude; live only for a real sweep.

### Notes, Cockpit, Milestones, People, Activity

6. Right-click a note in the Notes list → that note's menu (unpin, mark confidential and so on) opens without opening the note.
   - Test: no test found. Judgement.
7. With no project chosen, Cockpit and Milestones show "Choose a project" (not a blank page); choosing one fills the page.
   - Test: no test found. Judgement.
8. People: every zero looks the same (one kind of zero); the counts are right-aligned.
   - Test: no test found. Measurable.
9. Activity: an entry made by hand says "You, by hand"; rows are evenly spaced; every row has a tick box.
   - Test: no test found. Judgement.

### Draft email

10. Both Review items read "Draft email" (not "Chase").
    - Test: no test found.
11. "I sent it" updates every sent item and the email stays internal.
    - Test: no test found. Judgement plus a look at the item rows.
12. Right-click a person's name → Draft email for that person.
    - Test: no test found.

### One design scale

13. On every screen: fields are 32 px high, chips are 26 px pills, headings are 22 px and 16 px. Spot-check Work, Files, Settings, People, Review, Activity.
    - Test: no test found. Measurable; `dev/design-system/DESIGN-SYSTEM.md` has the method and the raw-value counts.
