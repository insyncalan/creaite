## Setup

**Automatic:** `just -f dev/justfile handchecks v1.9.5` (or `python3 dev/tools/handcheck.py v1.9.5`) does steps 2 to 7 below by itself in a throwaway folder, runs the automated checks, fills a copy of the Results table and makes the screenshot sheet (`sheet/index.html`, linking one page per theme and one for 320 px) for the judgement checks. The steps below are for checking by hand.

1. **Main.** In a clean checkout of `origin/main`: `VERSION` says 1.9.5, and the branches above are merged.
2. **The zip and a vault** (from the repository root):
   ```
   HC=$(mktemp -d -t creaite-hc)
   python3 dev/tools/build_release.py --out "$HC/zip"
   python3 -I system/scripts/update.py new-vault "$HC"/zip/creaite-*.zip "$HC/vault"
   ```
   **No `.creaite-dev` marker this time:** archiving never runs in the development repository. Instead, turn VIP alerts' automatic check off in Settings (or set `vip.check_minutes` very high), so nothing calls Microsoft 365.
3. **Sample data:** `mkdir -p "$HC/vault/dev/tools" && cp dev/tools/demo_data.py "$HC/vault/dev/tools/"`, then in `$HC/vault`: `python3 -c "import sys; sys.path.insert(0, 'dev/tools'); import demo_data; demo_data.load()"` (its command line, `demo_data.py load`, refuses outside the development repository, and this vault must not carry `.creaite-dev`; calling `load()` directly is what `handcheck.py` does). Add FAL, ORX, MER and TID to `project-register.md` (FAL's signals including the word "Falcon") and their owners to `people-register.md`. In Settings › People, set Rashid Al Suwaidi's VIP field on.
4. **Old files for BL-03** (today is 14-10-2026 when written; use dates over 12 months back):
   - in `projects/FAL Falcon Data Platform/reports/`: `2025-08-29 Falcon Data Platform weekly report.docx`, `2025-09-05 Falcon Data Platform client report.docx` and `2025-09-05 Falcon data notes.docx` (an ad hoc document);
   - in `projects/FAL Falcon Data Platform/minutes/`: `2025-09-02 FAL steering minutes.docx`;
   - in `projects/FAL Falcon Data Platform/transcripts/`: `2025-09-02 FAL steering transcript.docx`;
   - in `projects/_portfolio/minutes/`: `2025-09-10 Portfolio review minutes.docx`;
   - one recent file, `projects/ORX Orbit Customer App/reports/<last Friday> Orbit Customer App weekly report.docx`.
   Any small `.docx` will do (copy one from `system/templates/`).
5. **Stand-in Claude:** copy the `FAKE` stand-in from `dev/tests/test_run_chat.py` (it makes three tool calls, then a JSON and HTML reply) to `$HC/fake_claude.py` and `chmod +x` it.
6. **A calendar** for the Prep checks: write `$HC/vault/system/staging/hc-cal.json` (inside the vault: the run wrapper passes only paths inside the vault or the home folder) with a meeting today and one tomorrow (`{"days": {"YYYY-MM-DD": [{"id": "hc-1", "start": "10:00", "end": "11:00", "title": "FAL Steering committee", "where": "Microsoft Teams Meeting", "teams": true, "private": false, "organiser": true}]}}`), then, in `$HC/vault`, `system/scripts/run sweep.py calendar system/staging/hc-cal.json` and delete the file.
7. **Start:** in `$HC/vault`, `CREAITE_PORT=8990 CREAITE_CLAUDE="$HC/fake_claude.py" system/scripts/run live_server.py`. Open the printed address in Chrome. Ctrl+C stops it.
8. **Reset:** Ctrl+C, `rm -rf "$HC"`, then steps 2 to 7. A single change: Undo, or `system/scripts/run tracker.py undo`.

Chrome: DevTools › Rendering (`prefers-color-scheme: dark`, forced colours), the Device toolbar at 320 px, and a theme from Settings (creaite, Brightwater, Linear, Notion, Retro Arcade). Run on a weekday.
