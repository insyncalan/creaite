## Checks

### #259 Client output: the remaining gaps
1. A section whose stored audience says "client" is not trusted: the audience is worked out from the report, so a stored "client" on an internal-only section does not put it in a client export.
2. Plain words in stored fields that are not drawn (an item's values, a row's source or extra cells, tags, headings, the based-on path) are checked: a hidden item's words there are refused or dropped, and do not reach the filed report's data block.
3. Unknown inner keys in an item are dropped, not kept.
4. An item ID written oddly ("A B C - 0 0 5", "ABC-5", "ABC-0005") is read as the item it means and hidden when that item is hidden.
5. The snapshot test that was missing is present and passes.
6. **Live only, with Alan:** a real client export with the real logo still looks as before.

### #256 The Work page and saved columns
7. With saved column choices that hold only some of Actions, RAID and Decisions, the Work page opens, shows the saved columns for the tabs that have them, fills in the others, and changes nothing you saved.

### #255 Delete note
8. On the Notes tab, Delete note moves the note to the archive at once, with no approval card.
9. Undo brings the note back, unchanged; the delete is backed up and logged (Activity › What ask creaite changed is not involved: it is your own action).
10. The one-time approval for other card-only moves (a report, a project folder) still applies; a hand-staged proposal still cannot remove a note without the marker.
11. A confidential note, and a note deleted after ask creaite read outside content, behave as before (the guard is not loosened).

### #253 Log hygiene (second half)
12. A server failure that used to log an unhandled 500 now logs its cause (an error kind and where, never text).
13. After a sweep and after a failure the debug log still holds counts and IDs only.

### #252 The archive folder is "99 Archive"
14. A new project archive, a report archive and a deleted note go to a folder named "99 Archive" (inside the project's folder, and `<projects root>/99 Archive` for archived projects).
15. An existing `_Archive` or `zz Archive` folder is still read and never indexed for one release; restore from either works.
16. There is no rename offer and no migration: nothing moves by itself, and nothing breaks before or after Alan renames a folder by hand.
17. Stored paths (`projects/<folder>/…`) are unchanged; search, ask creaite and the Files page find archived items under the new name.
18. The settings' default for never-index and the Health page know the new name.
19. **Live only, with Alan:** the real OneDrive archive folder renamed once; other people's files inside are untouched and still there.

### #238 Your reviews (decided by Alan, 20-10-2026: follows in 2.5.3)
20. On the Usage tab, add a review note → it is saved with its date and kept after a reload.
21. Download as CSV gives the notes (date, what you saw, what you decided) and nothing else.
