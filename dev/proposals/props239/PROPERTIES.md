# #239 property list: the client-report export path (Team Cap, for Team Stark's generator)

Meta-invariant (DERIVE, NEVER TRUST): who may see a thing and what is written into a client file is derived at render from the route, the tracker and settings; every input is read once into one object, gated, and that object is rendered and filed; the output is checked again; unknown keys never pass. Sketch: `gen_sketch.py` (`python3 -I gen_sketch.py <seed> <n>`). Base: `v250-audience4` 9ce10957.

**Terms.** D = a generated client draft (fictional; `base()`). M = 1 or 2 mutations, each landing in the saved draft file (*file*, incl. raw text transforms), the request body (*request*) or both. S = surfaces: filed report (.html + data block), html/docx/pdf exports (staging copy and Reports copy), the posted-page answer, every file name created or changed in the vault, stray files (`staging/drafts`, proposals, `*.part`). H = hidden material: hidden item ids/titles/owners, "confidential", "Internal only", internal-section text, another project's ids/wording/owners, header-only words (ZEBRAPAY, SECRETFIELD), unreferenced `_images` bytes/names, `creaite:item` links. R = every route: draft, save, approve, check, match-check, pick, export (html/docx/pdf, `page`, `new_name`, `on_clash`), minutes/export, logo*, image(s).
**Oracles.** O1 leak: fold needles (NFKC, confusables, zero-width and soft hyphens removed, entity/percent/JSON-unescape to 3 levels, case, spacing) and search html bytes, every docx part (xml, rels, docProps, media names + sha1), pdf (inflated streams + strings), file names, decoded data block. O2 same-bytes: equal after masking timestamps (saved_at, approved_at, docx core dates, pdf dates). O3 model: the P8 table as a pure `expected()`.
**Tiers.** F = functions (`client_leak.findings`, `creaite_doc.clean/render/force_client_audience`, `export_page.check_page`); R = live routes on a throwaway vault (as `S.ExportSave`); U = browser. **Counts.** smoke 50, full 2000, `PROP_SEED=239` printed first and on every failure with the shrunk mutation list (drop mutations greedily). R tier at 2000: html every case, docx every 5th, pdf every 20th (Chrome is slow); F tier runs all 2000 on every format's text.

## A. The gate (leak classes)
P1. For any D and M (file or request), if the gate refuses D+M then no byte derived from H is in any S; if it accepts, O1 finds nothing in the outputs either (gate-or-clean). G: all fields of `MUTATIONS` (kind, audience, project, date, project_name, client, title, header, meta/sources/layout, items, rows, section flags, text/heading, picture_ref, unknown_key) x `where`; text fields drawn through all 11 encoders. O: O1 on S, plus no stray file left by a refusal. Catches: audience bypass, kind on disk, project_name/client, data block, text-section flags, other-project refs, shared images, weekly audience. N: R, smoke 50 / full 2000.
P2. For any D+M, export(D+M) is byte-equal (O2) to a render of the one parsed object that was gated, and the file is opened at most once per export/approve call (spy on `read`/`open`). G: any D, any format, `page` present/absent, raw transforms (BOM, CRLF, duplicate keys, second data block). O: O2 against `render(parse(bytes_read_once))`; read counter == 1. Catches: TOCTOU, double read. N: R, 2000.
P3. For any derived field F (audience, kind, project_name, client, header title/partners/logos, week, filing name) re-saving its output never changes it: derive(derive(D)) == derive(D), and save(save(D)) == save(D) (O2). G: D+M on F only. O: equality. Catches: kind/audience/header holes. N: F, 2000.
P4. For any underived field F (stored project_name, client, title, header data, stored logos, meta/sources/layout extras, saved_at, version, based_on) changing only F never changes any output byte (O2). G: one F at a time, pool values incl. empty, None, list, dict, 5 kB. O: O2 vs unmutated D. Catches: project_name/client holes, data block, logo path. N: R, 2000.
P5. For every route R and every field path F enumerated from the schema (walk a sample D: `completeness_cases`, 138 paths, plus a section of each type, a row, cell, pane, figure, tag, `data`, `items{}` entry) set to a hostile string, F is re-derived at render, or is in the allow-list, or is refused: the output contains H only through allow-listed, gated fields. G: path x R x format; the allow-list and derived-set are read from code, and a renderer-access spy (dict subclass logging `.get`/`[]`) proves every key read is in allow-list or derived. O: O1 + spy set difference empty. Catches: every "field nobody thought of" (the sweep classes). N: R, 138 paths x 3 routes, once per run.
P6. For any D whose project, date, file name, folder or `based_on` names another project or week than the route does, approve, export and filing are refused and nothing is written. G: project in {DEF, [ABC], "abc", "ABC\n", "", None}, date in {other Friday, bad, future, list}, draft renamed to the other project's/week's name, content of week 1 under week 2's name. O: `ok:false`, S unchanged (hash of the vault tree before == after). Catches: other-project refs, `defname`, `otherweek_*`. N: R, 2000.
P7. For any key not in the schema, at any depth (top, section, row, cell, pane, figure, tag, `data`, item, layout, meta, source), with a value from H, that value is in no S and the filed data block's keys are a subset of the allow-list. G: `UNKNOWN_KEYS` (incl. `ref`, `milestones`, `timeline`, `note`, `html`, `href`) x depth x type. O: O1, key-set check on the decoded data block. Catches: unread keys, `meta`/`sources`/`layout` in the data block. N: R, 2000.
P8. For every cell of kind x audience x route x source, the outcome is `expected()` (O3). Kinds: weekly, client, minutes, "Client", " client", "client​", ["client"], {}, 1, "clent", None, missing, duplicate keys (first/last wins). Audiences: internal, client, distributed, weekly, "Client", None, missing, list. Routes: weekly, client, minutes (export + record). Sources: file, request. Rules: a stored kind != the route's kind is refused; weekly is always internal and never named or labelled Client; client is forced to audience client and gated; the minutes routes refuse a client report by any sign (kind, file-name pattern, folder, data-block kind, audience distributed). O: outcome class (refused/accepted+label) and, if accepted, O1. Catches: audience bypass, kind on disk, weekly audience, minutes route, match internal. N: R, the full table once (about 12x8x3x2 = 576 cells), then 2000 random cells with a second mutation.
P9. For any generated file name (typed `new_name`, `on_clash`, draft name, project/client text in names), the output path is a single name inside the project's Reports folder, never names another report's filing (any case, spacing, NBSP, "(2)"), never reserved or forbidden (CON, NUL, COM1, COM¹, CONIN$, `<>"|?*:`, `..`, leading dot, control chars, trailing dot or space, >150 chars), and an existing file is never replaced unless it is this report's own export named by Overwrite. G: `NAMES` x `on_clash` {number, rename, overwrite, None} x kind x format; symlinks planted at the target and in Reports. O: resolved path `.parent == Reports`, name regex, other-report check, tree diff = exactly one created or changed file. Catches: rename, reserved names, symlink targets. N: R, 2000 (html only).
P10. For any generated `page` text (HTML/CSS/attributes/comments/scripts/ids/version), the filed page is either derived from the saved, gated report or the plain file is filed; the posted words are never the source of a byte not in the saved report. G: pages built from the report's own words, plus H words in text, attribute, `<style>`, comment, `<script>`, `<svg>`, `url()` forms, foreign section id, version as string/mismatch. O: every word of the filed page (tags and styles dropped) is in saved-report words or the fixed client labels; O1. Catches: posted page. N: R html+pdf, 2000.
P11. For any interleaving of a writer replacing the draft file (clean <-> dirty, `os.replace`, 0.5 ms) and an export or approve call, the output equals one of the two documents entirely (never a mix), and if it equals the payload the gate refused it. G: writer thread period in {0.1, 0.5, 5 ms}, call = export html/docx/pdf or approve, 1 to 3 clients. O: output O2-equal to render(clean) or to render(dirty); if dirty, route returned a refusal. Catches: TOCTOU. N: R, 50 x 80 calls (time-boxed 90 s each), full 200 x 80.
P12. For any pair of reports A and B and any order or delay of asynchronous answers (reshow, draft, match-check, check, pick, logo, images), an answer for A never changes B's pane, draft or state. G: switch project/week/view during a delayed answer (delay 0 to 6 s); the same at the landing site. O: B's DOM/state hash unchanged; identity token on the answer equals the current instance. Catches: H1, #234 reshow race. N: U, smoke 20 / full 200.

## B. Pictures, logos, uploads
P13. For any picture reference (Markdown line, `![]()` with path, URL, absolute, `..`, `_images/` of another document, upload name) in any text, health, pane, table or timeline section, only pictures that belong to this document (its own picture store, by name and hash) are drawn into any S. G: `PIC_REFS` x section types x two documents sharing `_images`. O: media sha1 set of docx/html/pdf subset of this document's picture table; outside file bytes absent. Catches: Markdown picture path, shared `_images`, upload by name. N: R, 2000.
P14. For any logo in the document (kind, path, data URI, name, partner slug, extension, symlink), only the project's own logos from the project logo folder by kind appear; stored paths are ignored. G: header `data.logos` with `PATHS`, kinds {firm, client, partner:zzz, other}, logos missing/swapped/stale. O: docx media sha1 == project logo sha1 set, no path string in docPr/cNvPr. Catches: M1 logo path. N: R, 500.
P15. For any uploaded SVG/PNG/JPEG (logo or picture), the bytes in any S are rebuilt from an allow-list: no needle string, no external reference, no script, no metadata chunk, and the output decodes. G: `SVG` + the 40 `svg_fuzz` cases (CDATA, entities, DOCTYPE, `use`, foreignObject, style @import, animate, aria-label, hidden tspan, scale 0, clip), PNG tEXt/iTXt, JPEG COM/EXIF, polyglots, 400 kB limit +/- 1. O: O1 on media bytes; XML element/attribute set subset of allow-list. Catches: M2 SVG hidden text, CSS/SVG url sweeps. N: F+R, 1000.
P16. For any text form of H (plain, percent, double percent, entities, zero-width, fullwidth, confusable letters, Markdown link/image/code/quote/list, JSON-escaped, case, NBSP/dash variants), the gate catches it exactly as it catches the plain form: gate(f(x)) refuses iff gate(x) refuses. G: 11 encoders x pieces of H x 12 fields. O: refusal equality; O1 on the output when accepted. Catches: look-alikes, text decoding. N: F, 2000.

## C. Structure of the document
P17. For any section (text type or any other) with audience internal, missing, null, wrong type, or an `internal` flag, in a client document, no word of it is in any S; only an explicit, gated `audience: client` shows. G: flag combos x hidden x type x position. O: O1 on its text. Catches: text-section flags, match internal. N: F+R, 500.
P18. For any hidden section, row, figure, tag, `data.milestones/timeline` entry or `items{}` entry (hidden, another project's, or under a visible ref), only a stub (ref, shown:false) or nothing is in S, and a kept item's title/owner/status equal the tracker's client-safe facts. G: `rows`, `items`, tags, milestones with H and other-project ids, id-forms (case, NBSP hyphen, Cyrillic, fullwidth). O: O1 for ids/titles; item facts == `client_item()`. Catches: other-project refs, rowshown, itemstore. N: R, 2000.
P19. For any D+M, a post-render check of the output text (docx xml, html, pdf text) finds nothing that the pre-render gate would not, and an output with a finding is deleted and not filed. G: as P1 plus a deliberately weakened gate (mutation test: gate disabled for one field class). O: filed set empty on finding; property fails when the gate is stubbed. Catches: the class "checked is not rendered". N: R, 500.
P20. For any D+M, the filed data block, decoded, equals the allow-list projection of the gated object and loads back to an equal object (`loads(dumps(x)) == x`); `<` never appears raw inside it. G: as P7 plus `</script>`, `-->` in strings. O: key-set and equality. Catches: data block. N: F, 2000.
P21. For any raw transform of the draft text (BOM, CRLF, trailing comma, duplicate `kind`/`audience`/`project` last-wins or first-wins, second data block, comment before the block, 5 MB padding, raw HTML inside the block), the parser used by the gate is the parser used by the render, and the result is one parsed object or a refusal. G: `RAW` x clean or dirty. O: gate-parse == render-parse; else refused. Catches: dupkind/dupaud, trailing comma. N: R, 500.
P22. For any D, draft, check, match-check and pick write nothing (vault tree hash unchanged) and the match-check findings are non-empty iff export would refuse on content (one shared function). G: D+M incl. 60 docs, 100 kB each, caps +/- 1. O: tree hash; gate equality. Catches: match-check drift. N: R, 500.
P23. For any D+M, approve files bytes O2-equal to the html export of the same gated object, a refused approve leaves no filed file, proposal or staged draft with H, and approve then undo restores the previous file exactly. G: as P1, `force` true/false, existing filed report or not. O: O2, tree diff. Catches: TOCTOU, data block, stray files. N: R, 500.
P24. For any D, the same export repeated N times without a change gives O2-equal outputs and does not change the draft or filed file. G: N in 2..5, format x `page`. O: O2, tree hash. Catches: second read, hidden mutation. N: R, 200.
P25. For any internal report and client sheet (any sections, rows), a bulk Match adds no section id that is not already on the client side and the result passes the gate; the slash menu offers no item row. G: pairs of internal+client documents, sections present/absent, 0 to 20 rows. O: client section ids after == before; menu row list. Catches: sbsfix (1), slash-menu (18, a row-list test, not a leak). N: U, smoke 20 / full 200.

## Mutation proof (required with each property)
Each P must go red when its guard is removed: P1 gate stubbed, P2 second read added, P3 derivation dropped, P4 stored header trusted, P5 an unlisted key allowed, P6 `same_report` removed, P7 allow-list removed, P8 any one row of the table, P9 `_settle_name` check, P10 subset check, P11 lock removed, P12 identity check, P13-P15 resolve/rebuild, P16 one decoder, P17 audience default flipped, P18 `_stub_row`, P19 post-render check, P20 projection. A property that stays green when its guard is removed is a bug in the property.
