## 4. Data and model changes
- **Transcript vs minutes ("by another person").** Everything added with Add files is someone else's by definition (creaite's own minutes live in the project folder, never in `inbox/`); no author metadata is read (docx `lastModifiedBy` is unreliable). Rule in `build_dashboard.file_kind(name, head)`, first match wins: (1) loaded from the calendar (event id) -> transcript; (2) `.vtt` -> transcript; (3) name has both "transcript" and "minutes|notes" -> unsure; (4) name has "transcript" -> transcript; (5) "minutes|notes" -> minutes; (6) for `.txt`/`.md` only, the first 4 KB: `WEBVTT` or three or more "HH:MM speaker:" turns -> transcript; two or more of Decisions / Action items / Attendees / Summary headings -> minutes; (7) else unsure (`ft:""`). A file starting "Draft, generated by creaite" is ours: unsure.
  Failure modes: "Meeting notes.txt" that is a transcript is misread as minutes (it then yields fewer items, no minutes; the switch link fixes it before Process); a minutes file named "...transcript review" is misread as a transcript (a duplicate draft of minutes, harmless, rejectable); PDFs and docx are name-only; a switch after Process is too late (the proposal records `kind` in its meeting block). The override is per browser (`creaite-ir-filekind`, keyed by path); another browser re-derives.
- **Calendar read time:** `D.meetings.fetched` (= `calendar.json` `fetched`, also `D.days.fetched`; Today's `calFoot` already formats it). No server change. It advances only when the refresh wrote a new calendar.
- **Add files:** `irAddFiles` -> `uploadInboxFile` (one upload path; 25 MB, five types; server strips path parts, never overwrites).
- **Stage boxes:** `irLiveCounts()` (+ `all`); `ready` and the badge exclude unsure files, as the mockup's `nProc()` does (Q5).
- **Find work items:** see E1. The inbox file is copied to the project's minutes folder as `YYYY-MM-DD Title.ext` on approval (confirm, Q10).
