# 228 (A, B, C): wording for system/creaite-rules.md (Jarvis to apply; guarded file, not edited here)

One piece, replacing the earlier 228 B and 228 A proposals.

1. **Folder map, project `CLAUDE.md`:** add the memory line `- **Partners:** Org A; Org B`: the project's partner organisations, one line, split on `;`, at most 12 names, each 1 to 60 characters of Unicode letters and digits, spaces and `. , & ' - ( )` only (no control, separator, bidi or zero-width character, no semicolon), one name once whatever the capitals or accents. Read by `build_dashboard.partners_of`, which skips a name that breaks the rules instead of failing, and makes each partner's slug; edited in the project settings page, which saves it with the same backup, log line and changed-file refusal as the client report lines and refuses a value with a line break or other control character for any label.

2. **Report logos (`system/branding/logos/`, local only, never in git):** `firm.<ext>`, `<CODE>-client.<ext>` and, for each partner, `<CODE>-partner-<slug>.<ext>` (slug = the partner's name in lower case, letters and digits joined by hyphens, at most 40, never ending in `original`). The older `<CODE>-partner.<ext>` is still read as the first partner's logo until that partner has a file of its own. In a layout or the memory line `Client report logos:` the kinds are `firm`, `client`, `partner:<slug>`; a bare `partner` means every partner, and a missing line means all. Removing a partner from the line deletes no file: the file is listed under **Logos not used** in the project settings, with a Remove button. The firm's logo is one file for every project; changing or removing it from a project says "for all projects" and asks first. A partner's name reaches a client only as its logo picture.

3. **Dashboard editing, Project settings page (#228):** `#project-settings=<CODE>[&c=<category>]`, opened from the project page's gear, the Projects list and Settings > People and projects. Categories as built: General, People and partners, Logos, Milestones, Reporting, Archive (no Workstreams: they stay in Settings > People and projects). A name or status is a project update applied at once with Undo; the code is changed only in ask creaite (`recode`); archive goes on the approval card. **Logos** has a row for the firm, the client and each partner (add, change, remove, and whether it shows on this project's reports) and a **Logos not used** list for orphaned partner logos; **Reporting** holds the client report switch, how often, the client's name and the reminder, the same single setting as the reporting hub's cog panel. The page writes no file of its own: every change goes through the store that already saves it.
