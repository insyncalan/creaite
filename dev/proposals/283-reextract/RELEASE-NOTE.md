# Release note line for #283 (review M2)

**Read again.** In a meeting's minutes, a new button, Read again, drafts the minutes afresh from the transcript. It asks first, shows its progress with Stop, and keeps your choices in the Track column where the same item comes back. Your earlier minutes are set aside, never deleted: Undo brings them back, and they come back by themselves if you press Stop, it can't finish, nothing new comes back, or it has a question. If the transcript has gone from where it was, Read again says so and leaves your earlier minutes as they are. It needs the guarded change in this release to be applied; until then it says it couldn't start.

Also in this release (review M2, no guarded change): the minutes a run stages never carry the client-visible flag from the transcript's own wording; a person sets it in Review.
