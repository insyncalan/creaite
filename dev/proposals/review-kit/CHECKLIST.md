# Review checklist: #239 step 1 (`v251-step1`), client output from one checked snapshot

Design: `git show origin/v251-snapshot-design:dev/proposals/client-output-snapshot.md`. Invariants I1 to I18: Team Cap's
comment on #239 (19:28), "FOR #239 / TEAM STARK'S DESIGN: the invariant each finding violated". Probe ids are in `INDEX.md`
(script, what it proves, args, known result); run them with `run_all.sh <checkout> <group>`.

Meta-invariant (I0): DERIVE, NEVER TRUST. What decides who may see a thing, or what is written into a client file, is derived at
render time from the ROUTE, the TRACKER and creaite's settings. Every input (request, draft file, stored document, upload) is read
ONCE into one in-memory object, gated, and that same object is rendered and filed. The output is checked again. Unknown keys never pass.

How to use: tick a row when the probe says PASS on the exact head AND the "also look at" line holds in the source. A probe that says
ERROR proves nothing (it never counts as PASS). `[GAP]` = no probe script covers it: do the manual step in the row.
Step 1 scope (design "Size and order" 1, plus the minutes refusal and the posted page): allow-list, render-time header/logos/kind/audience,
post-render check, one checked document under the lock, minutes refusal, posted page. Rules marked "step 2" are not expected yet.

## A. The six model rules

| # | Design rule | Probes that exercise it | Also look at (source) |
|---|-------------|-------------------------|-----------------------|
| M1 | **Snapshot**: built from tracker + project memory + the draft's TEXT only, never its stored header; checked once; written as `<name>.client.json` with its SHA-256 in `system/staging/client-snapshots.json`; never edited (step 2) | none yet. In step 1 the nearest is "one checked document": `race-export`, `race-approve`, `ms1-raw` | the object that was checked is the object rendered and filed (no second `read`/`loads` of the path between gate and render) |
| M2a | **One export function** `client_export(code, week, fmt)` is the only way a client Word/HTML/PDF is made | `ms2-export`, `ms2-approve`, `audbypass-*`, `rvaud-file-*` (every route and format) | `git grep -n "creaite_doc.export\|word_export\|_export_doc"`: every call on a client document goes through the one function; `creaite_doc.export`/`word_export` refuse a client document without the token argument |
| M2b | Runs **under the handler lock**, reads only the checked document | `race-export`, `race-approve`, `ms2-approve` (concurrent save + approve) | lock taken before the read, released after the file is written. Mutation: remove the lock, `race-*` must go LEAK or a named test red |
| M2c | **Hash verified** against `client-snapshots.json` | `[GAP]` step 2 | n/a in step 1 |
| M2d | **Post-render check on the OUTPUT text**: `client_leak` over the .docx XML, the .html, the PDF text, and a list of embedded pictures and their hashes against the allowed pictures. | M3 | **Derived at render, never stored**: header, `project_name`, `client`, kind, audience (always client), logos (`report_doc.logos(code)`), the week | header/client/title: `sweepclass-header`, `sweepclass-header-disk`, `ms1-header`, `ms2-fields`, `ms2-hot`. | M5 | **The server renders; the browser never posts the page**; `page` ignored on the export route; the page check shrinks to the post-render check | `ms2-page` (11 posted pages: hidden ID, hidden text, owner, confidential, internal marker, creaite link, other project's wording, internal section, header-like text, version as string, foreign section id), `atk-bg-svg`, `rv2b-imageset`, `rv241-v241`, `rc250-svg-inline`, `rc250-css-fuzz`, `rv241-atk-css`, `csp-check` | the route no longer reads `req["page"]`, or only accepts a SUBSET of the saved gated report (the `v250-pagefix` design). Re-run `ms2-page`: every case `needles=[]` |
| M6 | **Pictures**: only the project's `images/<name>` and the document's `_images/<name>`, plus logos by NAME from the project logo folder (no paths); by the snapshot's picture table | `rvlogofix-md-path`, `rvlogofix-route-md`, `rvmd-fuzz`, `rvmd-aud`, `ms1-pic`, `sweepclass-pic`, `ms2-misc`, `rc250-word-where`, `atk-other-paths` | I3 and I13; `paths.resolve_image`/`image_file` never touch an absolute, `..`, symlinked, hard-linked or other-project path |

| Route | Rule | Probes | Check |
|-------|------|--------|-------|

| `/api/report/save`, `/draft`, `/check` | behaviour unchanged; save keeps only allow-listed keys and never stores logos | `ms2-fields` (every field), `sweepclass-header`, `rvlogofix-route-logo` ("stored logos"), `rv234-reshow-race` (draft route) | the save result's `removed` list names the dropped keys; a re-read draft has the allow-listed shape |
| `/api/report/match-check` | gates the same function (shared code) | `rcleak-gate` (every PASSES row except `clean` is a miss), `ms2-misc` (match-check rows), `hostile-sbs`, `hostile-sbsfix` | `ms2-misc` "dirty" rows must have findings > 0 |
| `creaite_doc.export` / `word_export` | refuse a client document unless called by `client_export` | `[GAP]` by design (no script calls it as a user). `rc250-logo-path` and `atk-other-paths` call `word_export` directly | after step 1 they either refuse (ERROR with a token message is the design: read the log) or still produce a clean file; they must not embed anything outside |
| `report_doc.stage_client`, `client_check.left_out` | become steps of building the snapshot | `rvmd-aud`, `rvlogofix-md-path` (print `left_out` findings) | one gate function; `left_out(doc)` and `stage_client` give the same findings |
