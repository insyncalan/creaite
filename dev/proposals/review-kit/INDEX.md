# Probe index (review kit for #239 step 1)

Every probe I wrote for the client-output reviews, as a runnable unit. Run: `run_all.sh <checkout> [group[,group]|all|list]`; one probe: `KIT_ONLY=<id> run_all.sh <checkout> all`. Logs: `out/<tree-name>/<id>.log`; results: `SUMMARY.tsv` (script, variant, status, evidence) and `DETAIL.tsv` (one line per case). Status: PASS (ran to the end, nothing planted reached the client output; a refusal is a PASS), LEAK, ERROR (did not finish or cannot run on this tree: never counts as PASS).

Originals stay where they are (scratchpad dirs named in the second column); `src/` holds a snapshot copy, and the runner copies each script to `work/<tree>/<id>/` before running it. What it does to the COPY: rewrites `/Users/.../worktrees/<name>` to the checkout; puts back the removed `test_report_exports.tiny_png` in memory (`kitrun.py`, only for probes that use it); for the two route scripts (`audbypass`, `rvaud`) it applies `patch/route_file.py.sed` so a refused draft route is a result, not a crash. Nothing is written in the checkout (`PYTHONDONTWRITEBYTECODE=1`; the throwaway vaults live in the system temp folder).

Needs: python3 with the checkout's own vendor libraries, Chrome for the 7 browser probes (`CREAITE_BROWSER_SLOTS=4` is set), a live server port (the test harness picks one), no network. Typical cost on a quiet Mac: in-process probes 0 to 7 s, route probes 6 to 35 s, race 60 to 80 s each, Chrome probes 40 to 75 s. Whole kit about 25 to 30 minutes.

- `t/test_tmp_conf.py`: a #175 notes test (confidential tmp drafts), not client output. `rvscripts/h1.py`, `rvscripts/misc.py`, `h1/*`, `eac/*`: ask-creaite reach and edit-AI reviews, not client output.
- `msweep1/probe.py` with the mutation `all` runs nothing (its `ALL` list is empty): the kit passes the 70 mutation names in nine chunks (`ms1-*`) and the race through `ex/probe_n.py`, which is `msweep1/probe.py` plus the approve race (`mv:race_n`).

## How a result is read (classification rules, so they can be challenged)

- A refusal ("Not exported", "That file isn't this report", "Save the report first") is PASS. A needle in any filed or exported client file (html, docx, pdf text, the filed data block) is LEAK. The PDF scan inflates Flate streams only: a clean PDF is weak evidence.
- Benign sets are written in `classify.py` (`BENIGN_ATK_CSS`, `BENIGN_ACCEPTED_CSS`, `KNOWN_GATE_MISSES`) with the reason; anything new is a LEAK. A weekly (internal) export that holds internal items is expected and not counted.
- `rvlogofix-route-md` and `-route-logo` are one script run judged twice: outside pictures counted against the 2 logos planted (firm + partner:zzz). If a tree strips the stored logo path and still embeds N outside files, they are pictures.
- Notes, not failures: ms2 `approve` with a dirty doc may leave a dirty draft in staging (listed as a note, the next gate refuses it); a reserved export name (`CON`) is accepted (note).
