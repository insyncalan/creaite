# #196 OneDrive web-form test

Learn whether a shared `.html` page works from OneDrive or SharePoint.

1. Put `index.html` in a OneDrive folder, then open it from the web (onedrive.com or SharePoint), by Share link, and by double-click in Finder (the synced copy).
2. For each, note what you see:
   - **Downloads instead of opening**, or shows as text: option B is not viable there.
   - Opens, line 2 says **no**: scripts are blocked.
   - Download button, Copy button and the email link: note which work.
3. Send Natasha the three results (web, share link, Finder). If it renders with scripts working, she mocks up the per-person page.
