Restore from a backup

Puts this vault back as it was in a daily backup: the database, settings, staging and history. The current database and every file it replaces are kept first. Project files are never touched.

After every update, creaite does this for you

  • Backs up first, and rolls back if a step fails
  • Makes this vault's launcher again
  • Asks Chrome to refresh its copy of the app's icon
  • Restarts the live server on the new version, and runs the health check
