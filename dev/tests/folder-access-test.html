Folder access test

Checks whether this browser lets a local page read and write files in a folder you choose. This is option B for creaite's interactive dashboard (backlog BL-01).

When asked to pick a folder, choose an empty test folder (for example Desktop\creaite-test), never the creaite vault. The test only creates and then deletes one small file, creaite-test.txt.

1. Is the feature available?

Checks the browser, the page context and the folder-access feature.

2. Pick a test folder

The browser will ask for permission. Note any company policy message.

3. List the folder

Reads the file names in the chosen folder.

4. Write a test file

Creates creaite-test.txt. The browser may ask for edit permission.

5. Read it back, then delete it

Confirms the content, then removes the test file.

6. Does permission survive a reload?

Reload this page (F5), then run this step. It checks whether the browser remembers the folder without asking again.

Summary for IT

Run the steps above; the summary appears here.
