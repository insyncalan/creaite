## 2.1.0
Reports, minutes and notes now live inside creaite: a weekly report you edit on an A4 page, a client view of the same week, minutes beside their transcript, a Reports page and a reporting space on each project. The editor, Today, Review and the guard that protects your files also got a round of work.

### Before you update

- **No schema change and no migration** beyond what the update applies by itself.
- **Settings:** new keys are added with their defaults; every saved value is kept.
- **It replaces the engine only.** Nothing in your projects, reports or minutes is changed or moved.
- **Meeting hub retired.** Old `#meeting=` links land on the meeting's Prep or its minutes.
- **A full release**, not a pre-release. To install, say "update creaite".

### What is new

- **Weekly report:** twelve sections you can move, hide and rename, saved in creaite's own document format and exported to HTML, Word or PDF. Nothing is ever sent.
- **Client report (a Client view of the week):** only client-visible items, in the client's words, never anything Sensitive, partner-only or restricted. Check and export lists what is left out and why before any export.
- **Minutes view:** the transcript beside the draft, a time tag on every line, deadlines typed in words ("next Friday"), actions, decisions and risks approved unless removed, one apply with Undo. A follow-up email drafts from the version shown.
- **Reports page and reporting space** on each project, with a Friday reminder that points at Reports.
- **Notes:** a tidier header (+ New note, + Tags, typed dates), Delete note (moves to the project archive, restorable from Files > Archived), a checklist that aligns, a "/" menu, three heading levels and the "#" line.
- **VIP threads** show as cards: kind, ask, due date, owner and matching item.
- **✦ on report sections** redrafts a section; on the client report it can use only what the client may see.
- **Today, Review and small fixes:** Today at 80% width, Week ahead can be hidden, a wider Generate current state dialog, Review's multi-select bar follows you, Cmd+Enter saves any dialog, "Show changed only" is gone, two more switches stay visible in forced colours.

### Safer

- Runs that read outside content cannot write files or use built-in tools, and each run kind names the tools it may use (explicit `--tools`).
- Permission rules for connectors other than Microsoft 365 are refused.
- A report redraft and the client sheet use only client-visible items; a hand-staged proposal can no longer remove or copy a note.
- Held and ask runs: `~` forms other than `~` and `~/`, zsh `=cmd` words, `--`, wildcards that expand into hidden or staging folders, and `tracker.py validate` on a `~` or a wildcard are refused, through one shared rule table.
- Tool-less runs start in a neutral folder and no longer load your CLAUDE.md or notes as background.
- Clearer messages: a refused Apply says what to do, a Health fix that only raised an approval card says so, the live server says why it stopped, and the first page after a restart is faster.

### Not in this release

The sparkle and hover AI bar in notes, links in editors, Notes autosave and focus mode, the left rail changes, and Prep notes with AI arrive in 2.2.0.

### Known, for later

- Windows is best effort and untested.
- `test_close_day_card` can fail under heavy machine load (tracked as #137).

## 2.0.2
A security patch to the check that decides which commands ask creaite and the runs creaite starts may run. It closes a way a command could hide a second command from the check.

### Before you update

- **No schema change and no migration.**
- **No new setting.** Nothing is added or moved; every saved value is kept.
- **It replaces the engine only.**
- **A full release**, not a pre-release, so "update creaite" finds it with no version named. To install, say "update creaite".

### Changes

- **The shell-character check no longer misreads an escaped backslash before a closing quote.** A command written as `doctor.py "a\\" ; rm …` looked like one quoted word to the check, while the shell would have run the second command after the `;`. A backslash inside double quotes is now refused, so the check and the shell agree on where a quote ends. Single quotes keep backslashes as plain text, and a backslash outside quotes was already refused. The flaw has been in every version since 1.9.3; Claude Code's own permission rules were not tested against it.
- **Four skills (cx-minutes, cx-steerco, cx-weekly-report, cx-client-report) show the search summary step in single quotes**, because a backslash inside double quotes would now be refused. A summary written there must not contain an apostrophe; if it does, the check refuses the command and ask creaite retries.

### Known, for later

These are being fixed for 2.1.0:

- Held-run commands, ask creaite's chat commands and the newer built-in tools are still being tightened (the same checks as 2.0.1's notes).

## 2.0.1
A security patch. It narrows what the background Claude runs behind the VIP check, search and the drafting features can do, so a message or document they read can no longer make them run commands or change files.

### Before you update

- **No schema change and no migration.**
- **No new setting.** Nothing is added or moved; every saved value is kept.
- **It replaces the engine only.**
- **A full release**, not a pre-release, so "update creaite" finds it with no version named. To install, say "update creaite".

### Changes

- **The VIP check can only read Microsoft 365.** It now starts with no file, command or web tools, only the four Microsoft 365 reading tools, so it can't run commands or edit files even if a message it reads tells it to.
- **The search answer reads vault text only.** It now has only Read, Grep and Glob and no Microsoft 365 tools: it can read files in the vault, but can't run commands, edit files or reach the web. The tracker rows it needs arrive with the question, so an answer that needs more rows than were gathered may say the sources don't answer.
- **Drafting runs can't edit or write files.** Prep page, Current state, the AI drafts, Shape the meeting and the transcript checks can no longer edit or write files themselves; creaite writes the result.
- **Reply-only runs can't write files.** The Shape-the-meeting and Find-updates runs that only reply can no longer write files.

### Known, for later

These are being fixed for 2.1.0:

- **Held-run commands.** A run that has read outside content can still run some creaite staging commands. They are being restricted to read-only commands.
- **Newer built-in tools.** Built-in tools that no run needs are not yet removed one by one.
- **ask creaite's chat commands** don't yet get the same checks.
