# Project register

Keep this file at `projects/_portfolio/project-register.md`. Claude reads it every run, so update it whenever a project, stakeholder or channel changes.

## Projects

| Code | Project name | Folder under projects/ | Aliases / client names | Key stakeholders | Email domains | Teams channels | Keywords | Senders | Exclude |
|------|--------------|--------------|------------------------|------------------|---------------|----------------|----------|---------|---------|
|  |  |  |  |  |  |  |  |  |  |

Notes:
- **Code:** 3 to 7 capital letters or digits, starting with a letter (e.g. `ABC`, `ORX2C`); unique and never reused, including retired codes. Used in email subjects (`[ABC]`), meeting titles, channel names and project folder names (`projects/<CODE> <Name>`).
- **Key stakeholders:** list only people who are mainly on this project. People who span projects go under Shared.
- **Email domains:** list client or partner domains only. Never list your own company's domain (`identity.own_domains` in settings).
- **Senders:** individual addresses that mean this project (for example a client contact on a shared domain). Usually learnt when you choose a project in Review.
- **Exclude:** words that rule this project out, even when other signals match.
